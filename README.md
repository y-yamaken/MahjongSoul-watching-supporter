# 雀魂 観戦ウォッチ 0.3.4

雀魂を前面に出していなくても、観戦一覧を定期更新して指定ユーザーをWindowsへ通知するChrome拡張です。受信した一覧全体の名前を照合するため、スクロール外の名前も対象になります。

0.3.1では、疑似MouseEventの送信をやめ、Chromeのマウス入力機能で押下・解放を送ります。押下時間はこの入力の保持時間として使います。「動作確認」にはページで受け取ったChrome入力の押下・解放間隔を記録し、両方を受け取れた場合に「Chrome入力確認済み」と表示します。Unity内部のボタン表示そのものを測定する診断ではありません。追加の権限はありません。

0.3.2では入力の監視をページ読み込み開始時から登録します。ゲーム側が一部の入力イベントを先に処理する場合にも、自動クリックの押下・解放を見失って手動操作と誤判定しないための変更です。入力の不一致で停止した場合は、診断にイベント種別・段階・座標を記録します。

0.3.4では、自動クリックの準備開始から、解放後の画面処理が済むまで通常カーソルの移動・出入りをゲームへ伝えないようにしました。0.3.3では押下の保持中だけを対象にしていたため、解放直後の移動でクリック位置が変わる余地がありました。解放後は3回の描画更新を待ちます。この待機は最大1秒で、停止・画面変更・待機期限切れの際は解除します。実際のクリック、ボタンを押したドラッグ、キー入力、スクロールによる監視停止は維持しています。次の更新を待つ間や停止後のカーソル移動は制限しません。

## 修正版を反映する

1. Chromeの chrome://extensions で「雀魂 観戦ウォッチ」を再読み込みします。新しい権限の確認が表示された場合は、内容を確認して有効にします。
2. 雀魂のタブを再読み込みし、観戦一覧を開きます。
3. 拡張機能でユーザー名・更新間隔・押下時間を設定し、「更新ボタンを指定」を押します。
4. Chromeの操作通知が表示された状態で、雀魂の更新ボタン中央を1回クリックします。
5. 「位置を保存しました」の表示後、拡張機能を開いて「監視を開始」を押します。

開始後は別のタブやアプリへ切り替えられます。雀魂のタブは開いたままにしてください。0.3.0への移行時は位置指定をリセットします。ユーザー名と更新間隔・押下時間は引き継ぎます。

初めて導入する場合は、chrome://extensions でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で **extension** フォルダーを選びます。

## 追加する権限

0.3.0はChromeの **debugger（デバッグ）権限** を使用します。この権限はページの内容の参照・操作・画像取得が可能になる強い権限です。本拡張では接続先を日本版雀魂 https://game.mahjongsoul.com/ のタブに限定しています。

Chrome側で対象ページを描画・入力受付中として維持します。通常動作では画面画像を取得せず、URL・画面サイズ・Canvas内の位置を確認してからクリックし、新しい観戦一覧の応答で更新成功を判定します。利用者が選択している別タブや別アプリを自動で前面に戻す処理はありません。

使用中はChromeの操作通知が表示されます。「停止」、位置指定の中止、対象タブの終了・ページ移動、Chrome側での接続解除によって、監視と操作接続を終了します。通知帯を閉じたり、同じタブで開発者ツールを開いたりすると接続が解除される場合があります。その場合は監視も停止し、自動で接続し直しません。

## 動作

- 更新間隔は30〜3600秒、初期値は60秒です。監視開始直後にも更新します。
- 押下時間は0.1〜2秒、初期値は0.5秒です。現在の設定が1秒ならその値を引き継ぎます。
- ユーザー名は完全一致です。大文字小文字、全角半角、途中の空白を区別します。入力行の先頭・末尾の空白だけ除きます。
- 同じ対局IDとユーザー名の組み合わせは24時間・最大4000件のセッション履歴で重複通知を抑制します。同じユーザーの別対局は通知します。
- 「受信した一覧」に対局数・人数・名前と診断を表示します。通知をクリックすると、ユーザー操作として雀魂タブを前面に表示します。

ゲーム上での手動クリック・キー操作・スクロールや、画面サイズ変更・ページ移動は従来どおり監視停止の対象です。位置指定だけを済ませて監視を開始しない場合にも、拡張機能の「停止」から操作接続を解除できます。

## 監視範囲と制限

**対象は、雀魂が現在の観戦一覧として受信したデータです。** 他のカテゴリや、まだ受信していない対局を全サーバーから検索する機能ではありません。

Chromeが起動しており、雀魂がログイン済みで、対象タブが開いている必要があります。PCのスリープ中・Chrome終了中・ゲーム切断中は更新できません。Chromeが対象タブを休止した場合は、タブを再読み込みして開始し直してください。

更新操作自体は指定した位置へのマウス入力を利用します。背景で動作していても、観戦一覧以外へゲーム画面を切り替えないでください。位置指定時から画面サイズが変わった場合や、位置がゲーム画面の外・別のHTML要素の下になった場合は、誤操作を防ぐため待機または停止します。Canvas内の画面内容を画像で識別する機能はないため、ゲーム画面は観戦一覧のままにしてください。

同じタブを別の拡張機能や開発者ツールが操作中の場合は、接続できない場合があります。本拡張が他のデバッグ接続を強制解除する処理はありません。

## 通信とデータ

MahjongSoul-review-supporterを参考に、WebSocketで観戦一覧の要求と応答を対応付け、対局ID・開始時刻・ユーザー名を読み取ります。拡張機能が独自の要求番号でゲームAPIを再送する処理はありません。

名前は通信データから照合し、画面画像の取得やOCRは行いません。外部サーバーへ画像やユーザー名を送信しません。

ユーザー設定はChromeのローカル保存領域、位置指定・一覧・診断・通知履歴はブラウザーセッション内に保持します。「動作確認」のフォーカス値は、Chromeがバックグラウンド実行用に扱うページ状態です。実際にウィンドウを前面へ移動したことを示す値ではありません。

## 確認状況

単体テストでは接続先の制限、要求番号の対応付け、重複通知、バックグラウンド対象の位置確認、停止・接続解除・途中失敗時の後始末を確認します。

統合テストでは本物の拡張機能を独立したテスト用Chromiumへ読み込み、模擬観戦一覧の更新・名前照合・通知を確認します。疑似MouseEventを受け付けない模擬画面を使い、背景タブにChrome入力が届くことと、2秒・0.2秒の設定で保持時間が変わることを検証します。押下中と解放直後に連続移動を入れ、ゲームが解放を数フレーム遅れて処理する場合のクリックと通知も検証します。実際の雀魂サーバーへは接続しません。ゲーム側の通信形式や画面の変更には、利用環境での追加確認が必要です。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| Chromeの操作機能に接続できない | 同じ雀魂タブの開発者ツールや、操作中の別拡張を確認してください |
| 画面サイズ変更の表示が出る | Chromeの操作通知が表示された状態で、更新ボタンを指定し直してください |
| バックグラウンド接続が解除された | 拡張機能を開き、位置指定と監視開始をやり直してください |
| 指定ユーザーを検出しない | 「受信した一覧」に名前が含まれ、入力名と完全一致しているか確認してください |
| 更新に失敗して停止する | 「受信した一覧」内の「診断をコピー」で押下・更新要求・応答の有無を確認してください |

## 開発

Node.js 22以降を使用します。

~~~powershell
npm ci
npm run build
npm test
npm run check
npm run test:background
~~~

テスト用Chromiumがない環境では npx playwright-core install chromium を実行します。ユーザーのChromeプロファイルは使用しません。ポップアップの操作経路は npm run test:network でも確認できます。

src/network-main.js変更時は、npm run buildで配布ファイルを再生成してください。extension/には実行ファイルを同梱しています。

以前のOCR関連ファイルと比較用テストは残っていますが、0.3.0の実行時には読み込みません。参考コードの出所・ライセンスはTHIRD_PARTY_NOTICES.mdとextension/licenses/を参照してください。
